# 回响 / Take Stack

![Test](https://github.com/BrickerP/reverb/actions/workflows/test.yml/badge.svg)

在废件回收局，昨天的你会被复印、装订，再送回战场。《回响》是一款纸偶与办公废件构成的自动射击 roguelite：你控制走位，让武器自动攻击；每场战斗都会留下可再次部署、修补、合并或主动报废的回响。

当前源码是 **0.16 预览版**：三幕 12 场远征、三个不同 Boss、六种工作单、六名角色与各自主动技、35 把武器、有限生命的支援单位、跨局回响档案、三种终局，以及完整中途保存。画面与声音继续使用 **Carbon Copy Purgatory / 废件回收局** 的粗墨、旧纸和干燥机械质感。

## 怎么玩

- **完成三幕远征。** 每幕四场，4、8、12 场分别面对监工、收集者与悖论体。监工落下压印，收集者锁向冲锋，悖论体打出十字裁切；第 12 场获胜后可继续无尽或 Boss Rush，无尽在 16、20、24……场继续出现 Boss。
- **在大工场里走位。** 2400×1200 世界由镜头跟随，战斗区域与 HUD 保持分离并响应窗口尺寸。机器既能遮挡，也能通过 `E / X` 交互：压机有真实预警与伤害，传送带改变移动，回收机花费材料恢复生命和角色能量。
- **把工作单带进下一场。** 商店固定提供 6 件货：2 把武器、2 件被动、2 张不同工作单。打捞、审计、维修、营救、招募和信用单会改变下一场的目标、敌人或环境；同时只能持有一张，替换必须明确确认并可完整撤销。
- **经营六格装备。** 18 把基础武器各有两条终极分支，共 12 把终极武器，另有 5 把支援武器。等级 0–3 的伤害倍率为 1×、1.8×、3.2×、5.5×；报价按 `1.65^等级` 计价。第 5 场起，商店可按当前武器的同等级提供配对库存；两把同 ID、同等级武器可消耗一把并付装配费，让保留槽升一级并空出一个槽位。高等级配对可能需要跨场存钱，现金改装则是不消耗供体、但刻意更贵的稳定替代。
- **部署会受伤的支援。** 纸猎犬、哨戒炮、修补站、纸树和诱饵都有生命、持续时间和实际作用；招募单会在 Boss 倒地后暂停战斗，展示其专属条款；旧同伴进入候补名册，保留实际生命和剩余工时，商店可重新安排出勤。场上最多 12 个支援、最多一名招募同伴。纸树只提供有限护盾与能量，不制造免费现金。
- **手动拾取为主动技充能。** 亲自拾取材料会同时获得现金，并按每单位 4 点、单次最多 20 点补充角色能量；波末自动结算只给现金。能量满 100 后按 `Shift / LB` 使用角色技能，成功后进入 6 秒冷却。
- **维护过去的自己。** 回响会在战斗播放中磨损。轻按 `Space / RB` 消耗所选回响，释放由主导武器决定的技能；按住打开暂停选择轮盘。商店中可修补或用 `skill / repair / power` 三种供体特质合并；宿主保留完整路线与关键动作，预览不分配 UID，也不修改原件。每段录像最多保留 6 次机器操作或代表攻击，回放成功额外消耗 4 点耐久；普通自动射击仍适应当前敌人。
- **留下跨局档案。** 结算页可逐个查看并选择任意保留回响，覆盖旧档案前明确确认；标题页可预览并开关继承。每个有回响槽的角色只保留一张，拒收件、每日挑战与仍欠债的结算不能归档。继承回响占用正常槽位，开局伤害预算按初始武器的 0.75 倍规范化，辅助单位也降到开局等级；预览展示实际入场数值，耐久最多 60。

## 角色

| 角色 | 主动技（100 能量，6 秒冷却） | 解锁 |
|---|---|---|
| 折痕 / Creased | 倒回位置、回响播放和武器冷却 | 初始 |
| 拒收件 / Reject | 无回响；纸冲刺造成路径伤害并短暂格挡 | 最佳场次 4 |
| 套印件 / Misprint | 与所选回响交换位置并保留短暂锚点 | 通关 1 次 |
| 装订员 / Binder | 以所选回响为锚释放三次接力电弧 | 最佳场次 8 |
| 修补员 / Mender | 放置有限次数的修补站 | 最佳场次 3 |
| 超载员 / Overloader | 报废所选回响，按其当前耐久缩放强化爆发 | 最佳场次 7 |

主动技与回响报废是两套独立输入。角色技能失败时不会消耗能量，例如套印件没有可交换的回响、或修补员已触及支援上限。

## 工作单、债务与终局

| 工作单 | 下一场的实际变化 |
|---|---|
| 打捞 / Salvage | 三个零件必须在场内亲自交互，不能波末代收 |
| 审计 / Audit | 两台终端会产生真实危险区；累计完成两次审计取得放行资格并核销现有欠款，不替玩家选结局 |
| 维修 / Repair | 处理已存在的故障，修好后跨场保留；不买工单也能维修 |
| 营救 / Rescue | 危险工友会受到真实伤害；救援后进入安全名册，可提供一次援助或证词，不会变成诱饵 |
| 招募 / Recruit | Boss 倒地后进入暂停谈判；监工要求停机、收集者处理债务或证词、原件要求明确安排副本 |
| 信用 / Credit | 立即获得 30 材料并记 40 债务；普通工作单失败不会凭空加债 |

故障与危险工友由下一场的工况决定，购买工单只承接责任与报酬。商店可以先查看工况，再决定是否接单；账本可以主动偿还当前负担得起的欠款，没有手续费，也可撤销。

第 12 场战斗结束后，游戏暂停等待玩家决定：**放行**有放行资格时免费，否则支付 12 材料，修满现有回响；**共同离开**要求有实际幸存工友或同伴，带他们离开并回满玩家生命；**接管回收局**免费，但选择留任并把当前最后一份回响安排为员工。债务独立保留，不自动决定结局。选择期间可以保存并返回，继续后仍需签字。

## 操作

| 操作 | 键位 |
|---|---|
| 移动 | WASD / 方向键 / 左摇杆 / 十字键 |
| 开火 | 自动 |
| 角色主动技 | Shift / LB |
| 世界交互 | E / X |
| 报废所选回响 | 轻按 Space / RB |
| 选择回响 | 按住 Space / RB，松开确认 |
| 暂停 / 返回 | P / Esc / Start |
| 设置 | O |
| 对局记录 | H |
| 保存并返回选角 | 暂停时 Q，或暂停菜单按钮 |
| 静音 | M |
| 调试信息 | F3 / View |

菜单和商店支持鼠标、键盘焦点、十字键与 A/B。战斗 HUD 固定在画面上下边缘；底部仅保留紧凑装备与操作信息。960×540 使用真实响应式布局：选角每页 3 人，商店、结算、档案与 HUD 都保持按钮在屏内；世界视野随可用战斗区域调整，角色像素尺寸不做全局缩小。

## 保存与 0.16 兼容性

暂停菜单的“保存并返回”、标题页“继续”、窗口关闭和语言切换使用同一份 Snapshot v3。它保存完整战斗、商店交易和撤销、跨场机器和工友名册、回响关键动作及播放进度，以及未签署的招安或终局选择；读取先严格验证对象图，再替换当前会话。

0.15 及更早的对局快照不能继续。永久 Meta 数据（角色解锁、故事线索、回响档案）和设置保留；旧永久档案的关键动作默认为空。写入失败会保留当前对局与先前可用文件，并在正在操作的界面显示原因。

## 下载与源码运行

从 [GitHub Releases](https://github.com/BrickerP/reverb/releases) 下载已发布版本；0.16 构建与发布以对应标签页面为准。

- **macOS**：开发导出使用 Godot 内置 ad-hoc 本地签名，未使用 Developer ID，也未公证。
- **Windows**：开发导出未签名，可能触发 SmartScreen。
- **Linux**：给 `TakeStack.x86_64` 执行权限后运行。

从源码运行需要 **Godot 4.7.2**：

```bash
git clone https://github.com/BrickerP/reverb.git
cd reverb
make run
make run-zh
```

也可用 Godot 打开 `project.godot` 后按 F5。语言默认跟随系统，可用 `REVERB_LANG=en` 或 `REVERB_LANG=zh` 覆盖。

## 开发与验证

```bash
make test
make smoke
make perf
make frames
make export
python3 -m pip install -r tools/requirements-dev.txt
python3 -m unittest discover -s tests -p 'test_*.py'
```

这些入口来自当前 `Makefile` 与 CI。`requirements-dev.txt` 固定 NumPy 2.0.2 与 Pillow 11.3.0，只服务配乐/透明度工具和 Python CI；游戏运行不需要 Python。

验证覆盖中英文、原尺寸 1280×720 与 960×540、键鼠和手柄输入事件、低特效、严格保存恢复、工友/设备跨场结果、招安/终局选择、档案预览与实际入场数值。固定 96 敌人、8 回响、12 支援的压力场景另做性能与确定性对照；它不是人类难度或长期平衡结论。

当前仍未由真人或目标设备验证：长期平衡与主观趣味、实体手柄、Windows GUI、Steam Deck、低端硬件和跨设备 60 FPS。macOS 包为 ad-hoc 且未公证，Windows GUI 包未签名。

功能入口与验收范围见 [closeout-acceptance.md](docs/closeout-acceptance.md)。工程规则见 [DESIGN.md](DESIGN.md)、[INTERFACES.md](INTERFACES.md) 与 [主题收敛规则](docs/theme-convergence.md)；美术与战斗表现见 [art-direction.md](docs/art-direction.md) 与 [battle-direction.md](docs/battle-direction.md)；商店文案见 [STORE.md](STORE.md)。
