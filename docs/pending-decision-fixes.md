# 决定层

目标：玩家在确认之前能看出留下什么、花掉什么、得到什么，并且这句话和规则是同一个数。

这些项已落在 [PR #71](https://github.com/BrickerP/reverb/pull/71)。表内是验收，不是再做一遍。

| 项 | 验收 |
|---|---|
| 枪卡和升级用同一个数 | 新枪写每发、间隔、多占一格或换掉一格。升级写每发前后。没有总 DPS 箭头 |
| 第 1 场必须移动 | 还有敌人或待生成时，站着直到计时结束，场次仍在。场上已经空了，计时结束就进商店 |
| 选角不先教技能 | 焦点说明只有开局身份，没有主动技段落。锁定写「暂未放行」 |
| 利息和工单的下一场 | 利息写每 50 材料 +1、上限 5。工单写下一场有没有机器、工友、零件、终端 |
| 武器焦点只有决定句 | 选中武器时，底栏只有留下、消耗、得到 |
| 空回响栏一行 | 「活过一场才会留下路线。」 |
| 锁定不和购买并排 | 锁定在比较区，按钮写明免费以及换货后仍在 |
| 灰色按钮带原因 | 换货、撤销、不能出发、买不起、满槽，原因在按钮或卡面上 |
| 场上同一句 | 救援、检修、回收机都是 `[E] 动作 · 免费` 或价格 |
| 顶栏不写「生存」 | 没有工单时写「活过这场」 |
| 中文模式名 | `end.boss_rush` 中文是「首领连战」 |
| 买下之后能指认 | 槽位标「刚装上」。下一场该格第一次开火时，底栏写第几格和武器名 |
| 触发能看出谁得到什么 | 修补站、纸树、赊账哨塔第一次生效时，底栏写来源和受益者。机器修好后写「已停机」 |
| 第 1 场只有一句教学 | 不再画 WASD 条。回卷技能条不在第 1 场出现 |
| 合并一屏 | 同一屏列出留下的路线、消耗的副本、得到的特性和花费 |
| 招安没有地面入口 | 不再创建 `negotiate` 交互物。校验只看被击败的首领 |
| 旧说明书键删除 | 详情不再使用 `shop.detail` |

画风、空战场、材料像金币、六把相同枪的强度，不在这批。
