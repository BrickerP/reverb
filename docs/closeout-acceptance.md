maps a real UI/input entry to the current authoritative rule, named tests and
runtime evidence. Save, audio, gait, localization and release safeguards are

## Regression and release appendix

- **Save/continue:** Snapshot v2 preserves role/support/order/debt/shop/negotiation
  state; 0.14 suspended runs are intentionally incompatible, while permanent
  unlocks, archives and settings remain. Native Pause → Save/Return → Continue
  has exact one-step parity.
- **BGM/SFX:** five synchronized 96-second score arrangements and 35 dry SFX
  remain bounded; subjective listening approval is not automated.
- **Gait, i18n and input:** locomotion identity, EN/ZH text, Reduced Effects,
  keyboard/controller event routes and modal focus remain in the full suite.
- **Build proof:** root reports the current full suite at 21,382 checks with zero
  failures after the metadata/HP fix and local-cache rerun. Immutable platform
  exports, package receipts, movie and final public tag/URL are still pending;
  do not present native fixtures as the released build.
