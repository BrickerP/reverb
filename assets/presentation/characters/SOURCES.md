# Character action atlases

Twelve PNGs cover six original paper-puppet identities in front and back views.
The source identity, palette, ink treatment and camera angle are retained from
the approved four-pose artwork. All final atlases were generated or spacing-
refined with the built-in image generation tool on 2026-10-29 and copied to
the project without programmatic repainting or resampling.

## Layout and acting

Each atlas is 1536 by 1024 pixels, four columns by two rows. Each cell is
384 by 512 pixels. The eight row-major poses are idle, left step, right step,
hurt, action preparation, action follow-through, crumpling and flattened paper.
The extra gestures are original drawn poses, not transforms of one still image.
Back views remain faceless; weapons remain separate runtime-mounted artwork.

All eight cells are nonempty and distinct. At visible alpha >= 20/255, both
sides of all internal column boundaries and the middle row boundary are clear.
Frame-local alpha bounds and measured foot pivots are retained. Because drawn
poses differ in vertical placement, the renderer must use the measured per-frame
foot pivot with one shared live-actor scale; it must not assume equal row baselines
or rescale the living character from a wide flattened death pose. X pivots use
the fixed cell center.

## Files and provenance

- `../player.png`: Creased / Looper front
- `looper_back.png`: Creased rear
- `solo_front.png`, `solo_back.png`: Reject / Soloist
- `mirror_front.png`, `mirror_back.png`: Misprint / Mirror
- `conductor_front.png`, `conductor_back.png`: Binder / Conductor
- `mender_front.png`, `mender_back.png`: Mender, a patched repair apron, stapled
  cheek, rounded patch satchel and tape-spool tool belt
- `overloader_front.png`, `overloader_back.png`: Overloader, singed paper edges,
  tight stamp harness, pressure gauge and top-heavy stamp mechanism

`carbon_copy_assets.json` contains the exact initial and refinement prompts,
original output paths, preserved reference snapshots, byte hashes, dimensions,
frame hashes, alpha bounds and pivots. Original tool outputs remain intact.
Runtime `manifest.json` and `PresentationAssets` metadata are generated by the
offline `tools/sync_art_catalog.py` pipeline.

## New role artwork (2026-10-30)

Mender and Overloader are new original drawings using the existing player and
Conductor rear atlas only as style and camera references. Both retain the
cream/charcoal/sage palette, heavy-lidded reluctant acting and separate mounted
weapons. Back-view walking frame 2 was refined with the built-in tool to visibly
lift the opposite boot from frame 1. No programmatic drawing, cropping, alpha
replacement or resampling was used on the saved PNGs.

Each new atlas is exactly 1536 by 1024 RGBA and contains eight unique, nonempty
cells with clear internal grid boundaries at alpha >= 20/255. Runtime feet use
the measured alpha bottom of each pose and the fixed X cell center, rather than
assuming imagegen obeyed a common Y baseline. The initial and refinement
prompts, final and initial output paths, reference hashes, final byte hashes,
cell hashes and measured pivots are included in `carbon_copy_assets.json`.
